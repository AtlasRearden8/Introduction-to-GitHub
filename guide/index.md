# Introduction to GitHub 🚀

**A complete, friendly guide for absolute beginners, starting from square one.**

No coding experience needed, and no command line. If you can use a web browser and click buttons, you can learn this.

**32 chapters · 4 guided projects · a 30-day plan · templates, quizzes, and a cheat sheet**

[Start with Chapter 0 →](00-start-here.md){ .md-button }
[📄 Download the PDF](download.md){ .md-button }

</div>

Everybody who uses GitHub today started exactly where you are now. The confusing words (*commit! branch! merge!*) turn out to be simple ideas wearing fancy names, and this guide translates every one of them.
