# Introduction to GitHub

**A complete, friendly guide for absolute beginners, starting from square one. No command line: just GitHub Desktop and your web browser.**

You don't need to know how to code. You don't need to know what "Git" means. You don't need to type a single command. If you can use a web browser and click buttons, you can learn this, and by the end you'll be doing things that look like magic to people who haven't tried yet.

**32 chapters, 4 guided projects, a 30-day practice plan, templates, quizzes, and a cheat sheet.**

Everybody who uses GitHub today started exactly where you are now. The confusing words (commit! branch! merge!) turn out to be simple ideas wearing fancy names, and this guide translates every one of them.

## How to use this guide

- **Go in order.** Each chapter builds on the last.
- **Do the "Try it" sections.** Reading is good; doing is how it sticks. Each one takes just a few minutes.
- **Mistakes are safe.** Git is designed so you can almost always undo things. Chapter 10 shows you how, and you can read it any time you feel nervous.
- **Go at your own pace.** One chapter a day is a great rhythm. Some people finish in a weekend.

## A note on this guide

GitHub changes its buttons and menus from time to time. If something on your screen looks slightly different from what's described, don't worry. The *ideas* stay the same, and the names of things are usually close enough to find. The official docs at <https://docs.github.com> are always the final word on exact screens.
