# Fonts used in the PDF books

These font files are embedded in the PDFs so the books look the same on every computer. All three families are
licensed under the SIL Open Font License 1.1 (<https://openfontlicense.org>), which allows use, embedding, and
redistribution, including in books you sell.

| Family | Files | Project |
|--------|-------|---------|
| Plus Jakarta Sans | `pjs-*.woff2` | <https://github.com/tokotype/PlusJakartaSans> |
| Fraunces | `fraunces-*.woff2` | <https://github.com/undercasetype/Fraunces> |
| JetBrains Mono | `jbm-*.woff2` | <https://github.com/JetBrains/JetBrainsMono> |

The files come from the Fontsource packages (<https://fontsource.org>), subset to Latin.
